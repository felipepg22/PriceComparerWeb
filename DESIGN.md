# DESIGN.md

## Product Design Summary

The application is a search-first price comparison tool.

The homepage should help users quickly understand that they can search for a product and compare offers based on both price and store reliability.

The main design idea is:

> A trustworthy fintech-style interface for smarter online shopping.

## Visual Personality

The interface should feel:
- trustworthy;
- transparent;
- modern;
- calm;
- fast;
- objective.

It should not feel like:
- a coupon website;
- a noisy marketplace;
- an ad-heavy comparison portal;
- a generic ecommerce homepage.
